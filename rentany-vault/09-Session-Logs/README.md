## 2. Session Log Documentation Template

Every future session log must adhere to the following standard structure:

1. **Header & Context**: Date, local timestamp, active phase, session objective.
2. **Files Created, Modified or Deleted**: Absolute list of changed paths.
3. **Rationale & Decisions**: Why the changes were necessary and alternatives considered.
4. **Database & Configuration Changes**: SQL migrations, RLS adjustments, `.env` additions.
5. **Security Implications**: New attack surfaces or controls implemented.
6. **Tests Executed & Actual Results**: Exact commands run and empirical results.
7. **Known Limitations & Remaining Risks**: Active blockers or unresolved questions.
8. **Completion Status**: Complete, Partial, or Blocked.
9. **Single Best Next Action**: Clear tactical next step for the subsequent session.
